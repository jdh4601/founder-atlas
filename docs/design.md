# Founder Atlas 설계 문서 - 2026-09-25

## 한 줄 정의

AI 스타트업 창업자가 **특정 문제에 부딪혔을 때**, YC·a16z 등이 그 문제에 관해 말한 조언을
키워드 페이지 단위로 모아 보여주고, 원문에서 **필요한 구간만** 바로 확인하게 해 주는 개인용 웹앱.

## 독자

- 영어 원문을 읽을 수 있지만, 콘텐츠가 흩어져 있어서 맥락을 잡기 어려운 창업자.
- 첫 번째 독자는 본인(AI 스타트업 창업자). 당분간 **본인 혼자 비공개로 사용**한다.

## 핵심 결정

| 영역 | 결정 |
|------|------|
| 사용 순간 | 문제 해결형. 첫 화면은 피드가 아니라 문제 입력창 |
| 중심 단위 | 키워드 페이지 (미리 만들어 두고 사람이 검수) |
| 질문 기능 | 짧은 답변(2~3문장) + 페이지·구간 안내가 주 역할. 답변은 조언 단위만 근거로 사용, 근거가 없으면 생성하지 않고 기록 |
| 질문 기록 | 모든 질문을 저장. 매칭되지 않은 질문은 묶어서 새 페이지 후보로 사용 |
| 중간 층 | 조언 단위(advice) = 하나의 주장 + 원문 위치 |
| 분류 | 범주 8개 고정, 범주당 세부 키워드 최대 20개(시작은 5개) |
| 상황 속성 | AI, 단계, 업종은 범주가 아니라 "내 상황" 필터 속성 |
| 출처 | YC 유튜브, Lightcone, Paul Graham 에세이, a16z (4개) + 옵시디언 볼트의 인사이트 노트(`07_Insights`) |
| 분량 | 콘텐츠 100개 목표 |
| 검증 | 영어 인용문은 내부에만 저장하고 유사도 대조로 자동 검증. 사람은 키워드 페이지만 검수 |
| 타임스탬프 | 인용문이 일치한 자막 구간의 시작 시각을 코드로 계산 (AI 추정값 사용 금지) |
| 언어·어조 | 한국어 본문만, 인용문은 화면에 표시하지 않음. 가벼운 말투 + 사례 중심 |
| 시각 요소 | 개념 도식은 코드(Mermaid)로 생성. 썸네일은 원문 썸네일·대표 이미지를 가져온다. 원문 썸네일이 없는 Paul Graham 에세이만 글자 없는 AI 일러스트(`web/public/thumbnails/`)를 쓴다. 본문 그림은 `atlas add-figures`로 넣는다 |
| 콘텐츠 탐색 | 홈 하단(`/#contents`)에 소스 콘텐츠 그리드와 해시태그 필터를 둔다. `/explore`, `/map`은 이곳으로 이동 |
| 홈 배치 | 질문창 → 범주 탭(키워드 칩) → 콘텐츠 그리드. 질문하면 범주·콘텐츠를 숨기고 답변만 보여 준다 |
| 키워드 페이지 질문 | "이 주제로 더 묻기"는 해당 키워드의 조언만 근거로 답한다 (`/api/ask`의 `keyword`) |
| 설정 | 헤더 ⚙ 메뉴에서 화면 모드(시스템·라이트·다크)와 응답 모델 선택. 브라우저 localStorage에 저장 |
| backlink | 키워드 페이지 본문의 `[[slug]]` 링크 + "이 페이지를 언급한 페이지" 목록 |
| 공개 범위 | 비공개, 로그인 없음. "내 상황"은 `content/profile.yaml`에 고정 |
| 실행 | 로컬에서 먼저 사용하고, 안정되면 접근 제한을 걸어 배포 |
| 데이터 | Markdown 파일 (vault와 분리된 이 저장소의 `content/`) |

## 흐름

```
[수집]  discover → 후보 URL 목록 → ingest <URL> → content/sources/
[추출]  Claude Sonnet 5 → 조언 단위 후보 (한국어 요약·사례 + 영어 인용문 + 분류)
[검증]  인용문 ↔ 원문 유사도 대조 (rapidfuzz, 기준 90) → 통과분만 content/advice/
        자막이면 일치 구간의 시작 시각을 타임스탬프로 계산
[구성]  build-pages → 키워드별 조언 단위를 모아 content/keywords/ 작성 (reviewed: false)
[화면]  / 질문 입력 → /api/ask (Anthropic API 또는 로컬 Codex/Claude Code CLI 선택) → 짧은 답변 + 페이지·구간 안내
        /k/[slug] 키워드 페이지, 홈 하단 콘텐츠 그리드·해시태그 필터
[기록]  content/questions/log.jsonl
```

## 성공 기준 (4주 사용 후)

실제로 부딪힌 문제 가운데 70% 이상에서, 5분 안에 필요한 원문 구간을 찾았다.

## 범위 밖 (MVP)

- 로그인, 다중 사용자, 공개 블로그
- 영상 장면 캡처 (영상 다운로드와 ffmpeg가 필요하므로 이후 단계)
- 임베딩 검색 (키워드 페이지가 200개를 넘으면 도입)
