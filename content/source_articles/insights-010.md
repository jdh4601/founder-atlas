# 숏폼 마스터하는 법

## 핵심 전제

인스타그램 알고리즘은 더 이상 *"팔로워에게 잘 먹히는 콘텐츠"* 를 기준으로 배포를 결정하지 않는다.
나를 전혀 모르는 *낯선 사람이 멈춰서 보는 콘텐츠*를 기준으로 판단한다.

릴스를 올리면 알고리즘은 먼저 소수의 비팔로워에게 테스트 배포를 한다.
- 이들이 스킵하면 → 더 이상 배포 안 함
- 이들이 머물면 → 더 넓은 대상에게 확대 배포

따라서 모든 콘텐츠의 기준은 단 하나다.
>"이 영상은 나를 처음 보는 사람에게 3초 안에 흥미를 줄 수 있나?"

## 단계별 시스템

### 1단계. Creator DNA 정의

포지셔닝 없이 콘텐츠부터 만들면 결국 generic해진다.
아래 공식으로 자신의 정체성을 문장으로 만들어야 한다.
Creator DNA가 명확해야 콘텐츠가 자동으로 generic하지 않게 된다.

> "나는 00다. 나는 00사람들을 위해 00을 한다. 나를 들어야 하는 이유는 00다."

좋은 예시 (부동산 에이전트):
>"나는 밴쿠버의 부동산 에이전트다. 처음 집을 사는 사람들이 시장에 당하지 않고 감당 가능한 집을 찾도록 돕는다. 800건 이상 계약한 경험이 있고, 다른 에이전트들이 숨기는 것들을 공개한다."

나쁜 예시:
>"나는 부동산 에이전트입니다. 예쁜 집들을 보여드릴게요."

> [!NOTE] Example
> 나는 창업을 처음 시작하는 사람들에게, 1인 창업가들의 이야기를 듣고 용기를 주고 도움이 되는 이야기를 만든다. 나를 들어야 하는 이유는 진심인 창업가들의 경험을 듣기 위해서다.

### 2단계. 데이터 기반 콘텐츠 리서치

아이디어를 직감으로 떠올리면 랜덤이다.
이미 알고리즘이 밀어주고 있는 것을 분석해야 한다.

방법:
1. 인스타그램에서 내 청중이 검색할 키워드 3개를 검색
2. 조회수 높은 릴스/캐러셀 20~30개 수집
3. 스프레드시트에 다음을 기록
   - 주제
   - 훅 방식 (첫 3초를 어떻게 시작하는지)
   - 반복 패턴

추가로 TikTok, YouTube에서도 동일 키워드 검색 → 연관 검색어도 수집 → 다시 인스타에 넣어보기

분석 후 스스로에게 물어봐야 하는 질문:
>"이 주제에 대해 내가 다르게 말할 수 있는 게 뭔가?"

### 3단계. 훅 작성법 바꾸기

사람들은 이미 훅을 너무 많이 봐서 *"낚시성 문구"* 를 바로 알아챈다.
너무 대놓고 낚시처럼 느껴지면 스킵한다.

나쁜 훅 (마케팅 어투):
- "AI로 돈 버는 3가지 방법"
- "이거 모르면 손해입니다"

좋은 훅 (친구에게 말하듯):
- "어제 Claude한테 이거 시켰더니 진짜 황당한 게 나왔는데"
- "이거 아는 사람이 거의 없어서 올린다"
- "솔직히 나도 이게 될 줄 몰랐음"

>마케팅이 아닌, *흥미로운 것을 발견한 사람이 자연스럽게 공유*하는 것처럼 들려야 한다.

### 4단계. 비주얼 퀄리티 (카메라보다 조명)

낯선 사람은 첫 0.5초에 *"이 사람이 진지하게 콘텐츠를 만드는가"* 를 판단한다.
조명이 나쁘면 훅이 아무리 좋아도 신뢰가 생기지 않는다.

최소 투자로 최대 효과:
- 방 형광등 끄기
- 소프트박스 또는 링라이트 하나 (저렴한 것으로도 충분)
- 배경에 앰비언트 조명 추가 (포인트 조명, 간접 조명)
- 카메라는 스마트폰으로 충분

같은 폰, 같은 장소여도 조명만 바꾸면 완전히 다르게 보인다.

### 5단계. 배치 시스템으로 일관성 확보

매번 아이디어를 하나씩 만들면 느리고 질린다.

추천 워크플로우:
1. 주 1회, 아이디어 리스트에서 3~5개 선택
2. 한 번에 스크립트 작성 (뇌가 같은 모드일 때 더 빠름)
3. 다음 날 한꺼번에 촬영
4. 이 사이클을 반복하면 주 3~5개 업로드 가능

### 6단계. 분석할 때 패턴 보기

개별 릴스 하나가 망했다고 "이 방향은 안 되겠다"고 결론 내리면 안 된다.
최소 10~20개를 쌓은 후 패턴을 본다.

분석할 3가지:
- 조회수가 높은 콘텐츠의 공통점
- 팔로워를 늘려준 콘텐츠의 공통점 (조회수 높은 것과 다를 수 있음)
- *완전히 망한 콘텐츠의 공통점* (가장 가치 있는 데이터)

>매번 새로운 것을 시도하는 게 아니라.
>패턴이 보이면 → 그것을 반복하고 확장한다.

### 7단계. 이메일 리스트 연결 (조회수를 수익으로)

조회수와 팔로워는 인스타그램이 소유한다.
플랫폼이 망하면 사라진다. 이메일 리스트는 내가 소유한다.

1. 가치 있는 무료 자료 제작(템플릿, 가이드, 체크리스트 등)
2. 릴스 주 1~2개에 freebie 연결
3. Manychat 같은 도구로 자동화하기: 특정 키워드 댓글 → DM으로 자료 전송 → 이메일 리스트 추가
4. 이메일로 가치 제공

>이 구조가 완성되면 조회수와 무관하게 비즈니스가 돌아간다.
